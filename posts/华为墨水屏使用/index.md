## 01 / 准备

言归正传，博主也不能当一个标题党，自然是说到做到的。在我们第一步准备好设备后，需要拆屏+连接esp。

拆屏部分，建议使用吹风机或者打印机的热床加热手机壳几分钟，然后配合镊子和酒精基本可以做到无损拆机。拆机后需要焊接下屏幕先然后反向再安装回去，如图只要需要对好即可。

![](/assets/posts/华为墨水屏/20261013192955340.webp)

图片来源：[Bilibili: 华为墨水屏手机壳 DIY 教程](https://www.bilibili.com/video/BV1YzaJ6FEVd/)

然后按照如下线序接好屏幕与开发板

|屏幕信号|ESP32-S3 / ESP32-C3|
|---|---|
|SCK|GPIO4|
|MOSI|GPIO6|
|CS|GPIO7|
|DC|GPIO1|
|RST|GPIO3|
|BUSY|GPIO10|
|唤醒按键|GPIO5，按下接 GND|
最后效果大概如下，飞线尽量用较细的线或者漆包线，不然后面可能壳子有点放不下。3d打印方案可以去**makerworld**搜索。

![](assets/全网最简单的华为3.98彩显墨水屏使用/a6da3f4b39baa8015ba3c758766abf81.jpg)

02 / 烧录

## 不用搭编译环境，浏览器直接写入

重点在此部分，博主主要是在烧录方面做了优化。**不用搭编译环境，浏览器直接写入**。首先将你的设备找一条usb-c数据线接入你的电脑。电脑用 Chrome 或 Edge 打开在线烧录页面，选择与你的开发板一致的芯片。新设备选择**“首次烧录 · 完整包”**，点击“连接并选择设备”，选中 USB 串口，然后开始烧录。

在线烧录地址：  
[https://blog.moontung.top/Stillink/](https://blog.moontung.top/Stillink/)

已经安装 Stillink 的设备，也可以通过设备网页升级。完整烧录包与 OTA 包用途不同：首次 USB 安装用完整包，设备网页上传升级用文件名带 **-ota. bin** 的应用包。

![](/assets/posts/华为墨水屏/20261013193853158.webp)

 03 / 第一张照片
 
## 连接热点，选图，上传

烧录完成后，手机或电脑连接设备的 **Stillink-XXXX** 热点，在浏览器打开 **192.168.4.1**，进入“拍立得”，选一张照片，就能看到裁剪和四色预览。
![](/assets/posts/华为墨水屏/20261013194224487.webp)

裁剪、旋转、自然暖调、灰度、留白和文字，都在网页里完成。看好预览后点击**“上传并刷新屏幕”**，等待屏幕刷新结束，第一张桌面照片就做好了。

墨水屏刷新时会闪烁，完成一次更新需要等待。它更适合安静地展示照片与信息，不适合播放视频或实时动画。

 04 / 不只放照片
## 做一张随时能改的桌面便签

切到“便签”，写一句提醒、今日待办，或者喜欢的歌词。文字可以拖动、旋转，也能调整大小、颜色和底色，不用先去其他软件制作图片。

![](/assets/posts/华为墨水屏/20261013194247579.webp)

 05 / 连上家里的 Wi-Fi

## 以后不用来回切热点

在设备设置里点击 Wi-Fi 名称，选择家里的 2.4 GHz 网络并连接。连接成功后设备会关闭热点，手机和电脑在同一局域网内，通过设备 IP 地址访问即可。

![](/assets/posts/华为墨水屏/20261013194327310.webp)

06 / 可选扩展
## 天气、音乐和相簿，一次配置

只想放照片和便签，到这里就足够了。如果想让屏幕定时更新，再部署一份额外服务。中文字库、天气与音乐卡片渲染、相簿照片存储都放在电脑或服务器上，ESP 只请求最终的图片。

不会 Python 的 Windows 用户，可以下载 **StillinkServices-win. zip**，完整解压后双击 **StillinkServices. exe**。启动窗口会显示局域网服务地址，复制到设备的“额外服务支持”里，保存后才会出现扩展功能入口。

关闭窗口后，服务继续在托盘运行，右键可以退出。以后升级先退出服务，只替换 EXE，旁边的 **data** 文件夹要保留，里面存着照片和轮播列表。更适合长期运行的方案，是部署到树莓派或家中的服务器。

天气卡片可以选择城市或区县，显示当前天气和未来三天预报。默认每天 **08:00、12:00、18:00** 更新，也可以自己调整时间。

![](/assets/posts/华为墨水屏/20261013194357403.webp)

音乐需要另行启动 Windows 音乐广播工具 **StillinkMusic. exe**。播放器接入 Windows 系统媒体控件后，歌曲、歌手和封面通过局域网广播给服务，屏幕就可以在切歌时显示新的专辑卡片。

![](/assets/posts/华为墨水屏/20261013194408026.webp)

相簿保存的是经过拍立得处理后的展示画面，便签也能存进去。选好照片，开启顺序循环或随机播放，再设置切换时间，就能让桌面的画面慢慢变化。默认每 30 分钟切换一次。

![](/assets/posts/华为墨水屏/20261013194456474.webp)

tips: 天气、音乐和相簿轮播共用一块屏幕，启用一项会关闭另外两项。手动上传照片或便签成功后，也会停止自动更新，避免刚换好的画面又被覆盖。原来的配置会保留。

07 / 从这里开始

## 把屏幕用起来，再慢慢完善

如果你刚拿到这块屏幕，可以先完成三个动作：**接线 → 在线烧录 → 上传第一张照片**。等显示正常，再配 Wi-Fi，最后按需加天气、音乐或相簿，不必一次把所有服务都部署完。

项目地址：  
[https://github.com/sheetung/Stillink](https://github.com/sheetung/Stillink)  
固件、Windows 工具 ZIP 和完整说明，都在仓库与 Release 页面中。

一块小小的彩色墨水屏，可以放下你喜欢的照片、正在听的歌，也可以只放一句今天想看到的话。Stillink 想做的，就是让这些操作更直接一点。
